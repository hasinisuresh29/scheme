# Scheme Connect – Government Scheme Awareness Portal
> **Tagline:** Know • Access • Benefit  
> **Supporting Tagline:** Government Schemes for a Better Tomorrow  
> **Message:** "Right Information. Right Scheme. Better Livelihood."

---

## 🌟 Overview
**Scheme Connect** is a modern, responsive, professional, and accessible government scheme awareness portal designed to help Indian citizens—including rural families, farmers, students, daily-wage workers, women, senior citizens, and micro-entrepreneurs—discover government welfare programs, understand eligibility criteria, learn about benefits, and access verified official application links.

### 4. Interactive Eligibility Checker

### 10. AI Voice Assistant – Scheme Connect Voice Assistant (Requirements #17, #19, #20, #21, #22)
- **Floating Microphone Button:** Always accessible at the bottom-right corner of every page with a pulsing recording wave animation.
- **Bilingual Voice Recognition (STT):** Converts spoken English (`en-IN`) and Kannada (`kn-IN`) queries into text using Web Speech API with microphone permission handling.
- **Natural Voice Synthesis (TTS):** Speaks answers back aloud in English or Kannada with real-time waveform visualization, stop, replay, and mute controls.
- **Verified Information Engine:** Answers queries for farmers, students, women, workers, and housing without inventing criteria; provides direct `.gov.in` / `.nic.in` portal links.
- **Alternative Text Chat:** Full conversational text input with quick suggested question pills (e.g., *"Which schemes are available for farmers?"*, *"ನನಗೆ ಯಾವ ಸರ್ಕಾರಿ ಯೋಜನೆಗಳು ಲಭ್ಯವಿವೆ?"*), chat history clearance, and timestamps.
- **Preliminary Disclaimer:** Clearly reminds visitors that voice/text eligibility guidance is preliminary and final approval rests with the nodal department.

### 12. AI-Powered Document Verification & Quality Checker (Requirements #23, #24)
> **Feature Tagline:** *"Check Your Documents Before You Apply – Avoid Errors, Save Time."*
- **Dedicated Navigation Option:** Directly accessible from the sticky navbar (`#document-checker`).
- **Flexible Document Ingestion:** Drag-and-drop file upload (photos, scans, PDFs) plus live camera capture for mobile/desktop webcams.
- **Blur & Image Quality Analysis:** In-browser HTML5 Canvas Laplacian convolution kernel & brightness histogram detecting Clear, Warning (low contrast/overexposed), Blurry, or Incomplete/Cropped images with actionable photography advice.
- **Document Type Detection:** OCR and keyword classification identifying Aadhaar Card, PAN Card, Income Certificate, Caste Certificate, Residence Certificate, Ration Card, Bank Passbook, Educational Certificates, Birth Certificate, Disability Certificate, Land Records (RTC/Pahani), and Photographs.
- **Name Matching Verification:** Compares the applicant's entered name against document names with Levenshtein fuzzy distance and initial tolerance (e.g., *Rahul Kumar* vs *Rahul K.*).
- **Expiry & Renewal Deadline Checker:** Analyzes issue dates, validity periods, and provides advance renewal reminders (30, 15, and 7 days).
- **Scheme-Specific Document Checklist:** Automatically loads target scheme requirements (e.g., PM-KISAN, Ayushman Bharat, Gruha Lakshmi) and tracks live upload status badges.
- **Printable AI Document Summary Report:** Generates an overall assessment report (*Ready for submission review*, *Needs correction*, etc.) with printable/PDF export.
- **Privacy & Security Guarantee:** Zero cloud upload—all processing occurs strictly client-side; sensitive Aadhaar and bank account numbers are automatically masked (`XXXX-XXXX-1234`).

## 💻 How to Run the Website

### Option 1: Direct File Open (Zero Installation Required)
Simply double-click `index.html` in your file explorer to open the website in Google Chrome, Microsoft Edge, Mozilla Firefox, or any modern web browser.

### Option 2: Run with Local PowerShell HTTP Server
Open PowerShell in this directory and run:
```powershell
powershell -ExecutionPolicy Bypass -File .\start_server.ps1
```
Then visit **`http://localhost:8080/`** in your browser.
Press `Ctrl + C` in the PowerShell terminal to stop the server anytime.
